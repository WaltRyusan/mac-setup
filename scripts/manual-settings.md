# 手作業で設定するもの

`apply-macos-settings.sh` では設定できず、**GUI で操作するしかないもの**だけをまとめている。
スクリプトで設定できるもの（トラックパッド・日本語入力・Dock など）は、ここには載せていない。

---

## 1. Caps Lock を Control / Escape にする（英字/かなの切り替えにするならスクリプトで済む）

Caps Lock を **英字/かな の切り替え**にするなら `apply-macos-settings.sh` で設定済み（手作業は不要）。
**Control や Escape にしたい場合だけ**、GUI で設定する。

システム設定 → キーボード → 「キーボードショートカット…」→ **修飾キー** → Caps Lock を選ぶ。

| 割り当て | 向いている人 |
|---|---|
| `⌃ Control` | ターミナル操作（`^C` `^R` `^A` `^E`）を小指ひとつで打ちたい |
| `⎋ Escape` | Vim や Xcode の Vim モードを使う |

> 英字/かな の切り替えと同時には使えない。修飾キー側で Caps Lock を別の役割にすると、切り替えは効かなくなる。

## 2. Finder のサイドバーを整理する

Finder → **設定** → **サイドバー** タブ。`defaults` では設定できない（2026-10 実測）。

- **ユーザー名（ホームフォルダ）** を出す（既定では出ていない）
- **ハードディスク** を出す
- よく使う作業フォルダを足す（フォルダを選んで `⌘ + Ctrl + T`）

> **「ハードディスク」はチェックを入れても出ないことがある。** 一度外して入れ直すと表示される。

## 3. Spotlight からビルドの生成物を外す

インデックス作成の CPU の負荷が下がり、検索結果のノイズも減る。iOS・Android の両方をビルドする Mac では効果が大きい。
`apply-macos-settings.sh` で「Spotlight の検索から…」を選ぶと、設定画面を開いて追加するフォルダを表示する（追加は手作業）。

システム設定 → **Spotlight** → 「検索のプライバシー…」の ＋ で追加する。

```
~/Library/Developer/Xcode/DerivedData
~/Library/Developer/CoreSimulator
~/.gradle
~/Library/Android/sdk
```

プロジェクトの中の `build/`・`Pods/`・`node_modules` も、必要に応じて足す。

## 4. Chrome のタブを復元する

**同期しても、開いていたタブは自動では開かれない**（2026-10 実機で確認）。
ブックマークと**保存済み**のタブグループは同期されるが、開いていたタブは一覧として同期されるだけ。

新しい Mac で Google にログインしたあと、こうする。

1. `chrome://history/syncedTabs` を開く（または 履歴 →「他のデバイスからのタブ」）
2. 前の Mac の名前のところが出る
3. **右上の3点リーダーから一括で開ける**（1つずつクリックしなくてよい）

| | 新しい Mac での復元（2026-10 実機で確認） |
|---|---|
| ブックマーク | ✅ 同期される |
| 保存済みのタブグループ | ✅ 同期される（「グループを保存」したものだけ） |
| 開いているタブ | 一覧は同期される。**3点リーダーから一括で開ける** |
| ピン留め | ✅ 固定されたまま復元される |
| グループに入っていたタブ | ❌ 展開されてバラで開く |

> 前の Mac でグループを**閉じて**おくと、保存済みのグループとして復元できる。前の Mac を手放す前に済ませておく。
> 新しい Mac ですぐ使うページ（この README、GitHub の設定画面など）を前の Mac で開いたままにしておくと、
> 復元した直後からそろった状態になる。

## 5. Clipy のスニペットを移す

前の Mac で書き出したファイルを、新しい Mac で読み込む。

```
メニューバーの Clipy アイコン →「スニペットを編集」
  → 書き出し: 「エクスポート」ボタン ／ 読み込み: 「インポート」ボタン
```

> スニペットの実体は `~/Library/Application Support/com.clipy-app.Clipy/default.realm`。
> 同じフォルダの `sqlite.db` はクリップボードの履歴なので、移さなくてよい。
> ファイルを直接コピーする方法もあるが、Realm のデータベースなので版の違いで読めない可能性がある（未検証）。
> **エクスポート／インポートを使うのが確実。**

## 6. ターミナルのタイトルから「作業ディレクトリまたは書類」を外す

`apply-macos-settings.sh` の「zsh: ターミナルのタイトルに今いるフォルダのフルパスを出す」を選んだ場合、
ターミナルの既定の「作業ディレクトリまたは書類」と**フォルダ名が二重に出る**ので外す。

ターミナル → **設定**（`⌘ ,`）→ **プロファイル** → 使っているプロファイル → **ウインドウ** タブで、
**「作業ディレクトリまたは書類」のチェックを外す**。

| 項目 | 扱い |
|---|---|
| 作業ディレクトリまたは書類 | **外す（手作業）** |
| 作動中のプロセス名（`-zsh` など） | 残す |
| 大きさ（`187×57` など） | `apply-macos-settings.sh` で外せる |

> 設定のキーはプロファイルの中の `ShowRepresentedURLInTitle`（2026-10 に GUI の前後の差分で特定）。
> ただし `defaults` で書いても、**起動中のターミナルが設定を保存した時点で消される**（実測）。
> スクリプトはターミナルの上で動くため、ここは GUI で外す。
