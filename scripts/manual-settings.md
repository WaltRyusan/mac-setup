# 手動で設定するもの（GUI 操作が必要）

`apply-macos-settings.sh` だけでは完結しない項目。**新 Mac のセットアップ後に、この手順で設定する。**

手作業が残る理由は項目ごとに違う。**`defaults` のキーが特定できていないもの**と、
**書けるが再起動するまで反映されないもの**がある。後者は「スクリプトを流したのに効かない」という
気づきにくい失敗になるため、ここに書いておく。

---

## 1. トラックパッド：タップでクリック → **スクリプトで設定できる（要再起動）**

`apply-macos-settings.sh` の「タップでクリックを有効化」で適用される。
**ただし再起動するまで反映されない。**

「軌跡の速さ」だけは GUI で調整する（システム設定 → トラックパッド → 「ポイントとクリック」タブ）。
既定は遅いので右寄りに。

> **`killall` では反映されない（2026-10 / macOS 26.2 実測）。**
> 3ドメイン（`com.apple.AppleMultitouchTrackpad` / `com.apple.driver.AppleBluetoothMultitouch.trackpad` /
> `NSGlobalDomain com.apple.mouse.tapBehavior`）すべてに書き込んだうえで、
> `killall SystemUIServer`・`killall cfprefsd`・システム設定アプリを閉じた状態での書き直し、
> いずれも**値は書き換わるが挙動は変わらなかった**。
> **再起動（再ログインを含む）を挟むと反映された。**
> 再起動とログアウトのどちらが必須だったかは切り分けできていない。

## 2. トラックパッド：三本指でのドラッグ → **スクリプトで設定できる（要再起動）**

押し込まずに三本指でなぞるだけでドラッグできる。
`apply-macos-settings.sh` で適用される。**1 と同じく再起動するまで反映されない。**

GUI で設定する場合はこちら。

1. システム設定 → **アクセシビリティ**
2. **ポインタコントロール** → 「トラックパッドオプション…」
3. 「ドラッグにトラックパッドを使用」を ON
4. 方法を **「3本指のドラッグ」** に変更

> ⚠ **GUI は「トラックパッド」設定の中ではなくアクセシビリティ配下**にあるので見つけにくい。
> ⚠ 「調べる＆データ検出」を3本指タップにしていると競合する。どちらかを変更する。

## 3. Caps Lock の再割り当て

Caps Lock はホームポジションの左隣という良い位置にあるが、既定は「大文字固定」でほぼ使わない。
**何に割り当てるかは好みによる**ので、選んで設定する。

### A. 英字/かな 切り替え（おすすめ）→ **スクリプトで設定できる**

日本語を書く量が多いならこちら。**US キーボードだと `英数`/`かな` キーが無いので実質必須。**

`apply-macos-settings.sh` で適用される（**再起動不要・即座に反映される**）。手作業は不要。

GUI で設定する場合はこちら。

1. システム設定 → **キーボード** → 「入力ソース」の **「編集…」**
2. 左で **「すべての入力ソース」** を選択
3. **「Caps Lock キーで ABC 入力モードと切り替える」** を ON

> ⚠ この設定は「**修飾キー**」の画面ではなく「**入力ソース**」側にある。見つけにくい。
> 本来の Caps Lock（大文字固定）は `Shift + Caps Lock` で使えるので、機能は失われない。
> Karabiner-Elements は不要（macOS Catalina 以降の標準機能）。
> キーは `NSGlobalDomain TISRomanSwitchState`（`com.apple.HIToolbox` ではない）。

### B. Control に変更

ターミナル操作（`^C` `^R` `^A` `^E`）が小指ひとつで打てる。

システム設定 → キーボード → 「キーボードショートカット…」→ **修飾キー** → Caps Lock を `⌃ Control` に。

### C. Escape に変更

Vim / Xcode の Vim モードを使うなら。上記と同じ画面で `⎋ Escape` を選ぶ。

## 4. 日本語入力（ライブ変換 OFF ＋ Windows風のキー操作 ON）→ **ほぼスクリプトで設定できる**

**この2つはセットで考える。**

- 「Windows風のキー操作」を ON にすると **Enter 1回で変換を確定**できる
- ただし **ライブ変換が ON のままだとこれが機能しない**

`apply-macos-settings.sh` で、ライブ変換 OFF・Windows風のキー操作 ON・タイプミス修正 OFF の
3つが適用される（**再起動不要・即座に反映される**）。

**`¥` キーの設定だけは GUI で行う。**

1. システム設定 → **キーボード** → 「入力ソース」の **「編集…」**
2. 左で **日本語** を選択
3. **「¥キーで入力する文字」→ `\`（バックスラッシュ）** にしておくと開発時に楽

> `¥` キーは `JIMPrefCharacterForSlashKey` というキーに対応していそうだが、
> **どの値がどちらを意味するかは未確認**のためスクリプトに入れていない。
> 他の3つは `com.apple.inputmethod.Kotoeri` ドメインの
> `JIMPrefLiveConversionKey` / `JIMPrefWindowsModeKey` / `JIMPrefAutocorrectionKey`。

## 5. Finder サイドバーの整理

Finder → **設定** → **サイドバー** タブ

最低限チェックしておきたいもの。

- **ユーザー名（ホームフォルダ）** ← 既定では出ていない
- **ハードディスク**
- よく使う作業フォルダ（`⌘ + Ctrl + T` で任意のフォルダを追加）

> ⚠ **「ハードディスク」はチェックを入れても出ないことがある。** 一度外して入れ直すと表示される。

## 6. Spotlight からビルド生成物を除外

インデックス作成の CPU 負荷が下がり、検索結果のノイズも減る。
**iOS / Android 両方をビルドする Mac では効果が大きい。**

システム設定 → **Spotlight** → 「検索プライバシー…」に追加する。

```
~/Library/Developer/Xcode/DerivedData
~/.gradle
~/Library/Android/sdk
```

プロジェクト配下の `build/` `Pods/` `node_modules` も必要に応じて。

## 7. Dock に並べるアプリ → **スクリプトで設定できる**

当初 `dockutil` が必要と書いていたが、**`defaults` だけで設定できることを実測した（2026-10）。**
`apply-macos-settings.sh` の「Dock に並べるアプリを設定する」で適用されるので、手作業は不要。

> `persistent-apps` は plist の入れ子配列だが `-array-add` で追加できる。
> `_CFURLStringType` は `0` を渡せば macOS 側が `file://` 形式（type=15）へ正規化する。
> `killall Dock` で即座に反映される。

並び順を変えたい場合は `apply-macos-settings.sh` の `dock_add` の順序を編集する。
未インストールのアプリは自動でスキップされる。

旧 Mac の並び順は、`audit-old-mac.sh` の出力 `macos-settings-diff.txt` の末尾にも記録される。

## 8. Chrome のタブを復元する

**同期しても、開いていたタブは自動では開かれない**（2026-10 実機確認）。
ブックマークと**保存済み**タブグループは同期されるが、タブは一覧として同期されるだけ。

新 Mac で Google ログイン後、こうする。

1. `chrome://history/syncedTabs` を開く（または 履歴 →「他のデバイスからのタブ」）
2. 旧 Mac のデバイス名のセクションが出る
3. **右上の3点リーダーから一括で開ける**（1つずつクリックしなくてよい）

> ⚠️ **グループに入っていたタブは、グループとして復元されず展開されてバラで開く。**
> 旧 Mac 側でグループを**閉じて**おくと、保存済みグループとして復元できる。
> 旧 Mac を返却する前に済ませること（`audit-old-mac.sh` の手動タスクに記載）。

| | 新 Mac での復元（2026-10 実機確認） |
|---|---|
| ブックマーク | ✅ 同期される |
| 保存済みタブグループ | ✅ 同期される（「グループを保存」したものだけ） |
| 開いているタブ | 一覧は同期される。**3点リーダーから一括で開ける** |
| **ピン留めの状態** | ✅ **固定されたまま復元される** |
| グループに入っていたタブ | ❌ 展開されてバラで開く |

### 旧 Mac を離れる前に、必要なページを開いたままにしておく

タブは一括で復元できるので、**引き継ぎ用のページを開いたまま**にしておくと、
新 Mac で開いた直後からそれらが揃っている状態になる。開いておくとよいもの。

- 引き継ぎ用の Google ドライブフォルダ（`new-mac-setup`）
- Git ホスティングの SSH 鍵の登録画面

固定タブはそのまま固定で復元されるので、**常用するものは旧 Mac で固定しておく**とよい。

## 9. Clipy のスニペットを復元する

旧 Mac で書き出したファイル（引き継ぎ用フォルダに入れてある）を読み込む。

```
メニューバーの Clipy アイコン →「スニペットを編集」
  → 編集画面の「インポート」ボタン → ファイルを選ぶ
```

書き出しも同じ編集画面の「エクスポート」ボタン。

> スニペットの実体は `~/Library/Application Support/com.clipy-app.Clipy/default.realm`。
> 同じディレクトリの `sqlite.db`（30MB前後）は**クリップボード履歴**なので移行不要。
> ファイルを直接コピーする方法もあるが、Realm DB のためバージョン差で
> 読めない可能性がある（未検証）。**エクスポート／インポート機能を使うのが確実。**

## スクリプトでやる分

以下は `apply-macos-settings.sh` が担当する。手でやる必要はない。

スクリーンショット（保存先・影・形式）／ Dock（位置・サイズ・自動非表示・表示遅延・
最小化エフェクト・最近使ったApp・スペース自動並べ替え・アプリ構成）／ Finder（パスバー・
ステータスバー・隠しファイル・拡張子・表示形式・検索範囲・拡張子変更の警告・
ネットワークの .DS_Store）／ キーボード（キーリピート・長押しアクセント・スマート引用符／
ダッシュ・スペル自動修正・F1/F2・**Caps Lock の英字切替**）／ **日本語入力**（ライブ変換・
Windows風のキー操作・タイプミス修正）／ **トラックパッド**（タップでクリック・三本指ドラッグ）

```bash
bash skills/util-mac-migration/scripts/apply-macos-settings.sh --dry-run   # 確認
bash skills/util-mac-migration/scripts/apply-macos-settings.sh             # 対話で適用
```

> **実行前にシステム設定アプリを閉じること。** 開いたままだと終了時に古い値で上書きされる。

**反映のタイミングが項目で違う。**

| 反映 | 項目 |
|---|---|
| 即座 | Finder / Dock / スクリーンショット / Caps Lock の英字切替 / 日本語入力 |
| 再ログイン後 | キーリピート / F1・F2 |
| **再起動後** | **トラックパッド（タップでクリック・三本指ドラッグ）** |

トラックパッドは `killall` では反映されない。**設定直後に効いていなくても失敗ではない。**

全項目の背景・`defaults` の確度評価は `references/macos-settings.md` を参照。
